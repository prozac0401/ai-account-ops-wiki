## 도구를 구분한다

| 도구 계열 | 대상·권한 | 범위와 한계 |
|---|---|---|
| Cursor 초기화 V3 | 001–042, Windows 11 x64, 비관리자, PowerShell 미사용 설계 | 현재 Windows 사용자의 Cursor 데이터와 Chrome·Edge 인증 관련 쿠키를 선택 정리. 일반 방문 기록·북마크·무관한 데이터를 보존하는 방향 |
| Reset 00–48 계열 | 00–48 계정, 관리자 권한의 광범위 브라우저 초기화 | Cursor V3와 삭제 범위·권한이 다름. 정확한 버전 README 없이는 실행하지 않음 |

F02에는 WSH·SQLite 보조 도구가 언급된다. 담당자에게 중요한 것은 구현 방식보다 **누구의 어떤 데이터가 지워지는지**다. 계정 번호 체계와 PC 수를 서로 바꿔 사용하지 않는다. 42명 과정, 49계정, 48대 PC는 서로 다른 기록이다.

## 실행 전 승인

아래는 조직 채택 전 운영 제안이다.

1. 대상 PC, Windows 사용자, 이전·다음 배정 계정 별칭, 과정, 도구 버전·해시를 맞춘다.
2. 버전별 삭제 범위와 보존 대상을 읽고 필요한 실습 결과물을 승인된 위치에 보관한다.
3. 교육 담당자가 사용 종료를 확인하고 계정 관리자가 세션·개인 작업 유무를 확인한다.
4. 관리 권한이 필요한 도구를 비관리자 도구처럼 안내하거나 범용 프로필 삭제 명령으로 대체하지 않는다.
5. 단일 PC 시험 후 결과와 복구 방법을 승인받아 확대한다.

## 최종 앱 계정 확인

키 입력 성공, 브라우저 로그인 완료, 계정 선택 버튼 클릭은 Cursor 앱 로그인 성공이 아니다.

1. 초기화 결과를 기록하고 지정 계정으로 로그인한다.
2. 브라우저 인증 후 Cursor Desktop으로 돌아온다.
3. **실제 앱 Settings의 계정과 Team**을 계정-좌석-PC 대장과 대조한다.
4. Privacy Mode와 실습 레포를 확인한다. 이전 계정이 남아 있으면 인계를 중단한다.
5. 앱 계정 확인자·시각, 성공·실패, 다음 조치를 비밀정보 없는 로그에 남긴다.

## 버전이 불명확한 기능

`__AI_EDU__`, `W` 키, 시작 시 1회 실행(startup-once), 실행 후 자기 삭제는 대화에서 회수된 단서다. F02 V3 메뉴의 E/P/A/C/R/L/Q와 W를 혼합하지 않는다. 어느 버전에 포함되는지, 삭제·복원 범위가 무엇인지 확인할 원본이 없어 현재 공통 기능으로 채택하지 않는다(U11).

실제 전체 PC 초기화 완료와 현장 인수 결과는 확인되지 않았다(U18). 파일이 존재한다는 사실을 배포·실행·검수 완료로 바꾸지 않는다.
